# kowrap v0.2.0

React 중심의 초기 버전에서 벗어나, 일반 HTML과 여러 프론트엔드 프레임워크에서 공통으로 사용할 수 있는 한국어 줄바꿈 라이브러리로 확장했습니다.

## 새로운 기능

- 일반 HTML·JavaScript용 `mountKowrap` 및 데이터 기반 `observeKowrap`
- Vue 3용 `kowrapDirective` 및 Svelte 5용 `kowrap` 액션
- React `useKowrap` 훅과 강제 줄바꿈 상태 제어
- `forcedBreaks`를 통한 UTF-16 위치 기반 의도적인 줄바꿈
- `splitLines`를 통한 SSR 초기 개행 계산
- `WrapText`와 `SentenceText`의 강제 개행 지원

## 아키텍처와 성능

- 코어 엔진, DOM 기능, 프레임워크 어댑터의 책임 분리
- Greedy 전략이 모든 후속 후보를 계산하지 않고 현재 줄부터 순차 탐색
- Canvas 측정 재사용 및 글꼴 변경 시 정확한 재측정
- 기존 `/browser` 진입점 유지 및 `/dom` 별칭 추가

## 검증과 문서

- 코어, 아키텍처, SSR, React 하이드레이션과 프레임워크 어댑터 테스트
- Vue·Svelte 런타임 및 Chromium 통합 테스트를 릴리스 검증에 추가
- 일반 HTML 실행 예시와 한국어 개발·사용 문서

## 호환성

기존 0.1.0의 공개 import 경로를 유지합니다. 간단한 텍스트는 이전과 동일하게 사용할 수 있습니다. 구현 파일의 내부 경로에 직접 의존하는 경우 공개 패키지 진입점으로 전환하세요.
