# Kowrap v0.3.0

## Inline markup

- React `WrapText` now accepts nested inline JSX such as links and emphasis, while retaining support for plain strings. Initial server output preserves the markup and manual breaks. The browser measures and applies automatic breaks after hydration.
- Plain HTML `mountKowrap`, the Vue directive, and the Svelte action support `inline: true`. They measure the text of inline elements using their computed styles and preserve the original elements and event handlers.

## Wrapping accuracy and stability

- Balanced wrapping prefers keeping common Korean modifiers with their nouns when the words fit together without adding a line.
- Browser adapters use the observed content width and the measured element's language for font fallback. The first measurement uses the resolved CSS content width when it can be verified, reducing extra breaks before the observer reports.
- Rendering from resize notifications is deferred outside observer delivery, including in WebKit.

## Website and guides

- The landing compares the same sentence with and without Kowrap. The editor is visible on arrival and updates both results as the sentence, width, or font size changes.
- The HTML guide includes a standalone CDN example. The guides provide more detail on choosing an API, handling dynamic content, and troubleshooting measurements.
- The page table of contents highlights the section being read on desktop and mobile.

Existing public import paths remain available, including `@oddmash/kowrap/browser` and `@oddmash/kowrap/dom`. No framework migration is required for plain-text callers.
