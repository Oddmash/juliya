# Juliya (줄이야) v0.4.0

- Introduce Juliya, a locale-aware text wrapping library for Korean, English, Japanese, and Simplified Chinese.
- Add explicit locale selection and the `./ko`, `./en`, `./ja`, and `./zh` entrypoints while retaining the Korean default and existing Kowrap imports.
- Add `JuliyaProvider`, `JuliyaText`, and `useJuliya` for React locale inheritance; retain `WrapText` and `useKowrap`.
- Localize the landing, guides, navigation, and search, improve live measured reflow specimens and wrap explanatory gallery copy.
- License the original source and documentation under MIT. Bundle the license and attribution notice in both package artifacts.
- `@oddmash/kowrap@0.4.0` is the final release of the legacy package. Future updates and fixes will be published exclusively as `@oddmash/juliya`; existing Kowrap versions remain available.

The official package moving forward is `@oddmash/juliya`.
