# Juliya (줄이야) v0.4.2

## Highlights

Improve inline DOM layout stability and make the package and localized documentation easier to discover.

## Fixes

- Preserve Korean technical noun phrases in balanced wrapping (#131).
- Avoid redundant plain-text resize measurements (#122).
- Preserve existing generated inline breaks when the break offsets remain unchanged, reducing unnecessary DOM changes on refresh.
- Coalesce font and resize notifications and avoid equivalent resize-only layout work.

## Documentation and maintenance

- Add the official package homepage, search keywords, and a sitemap for the localized documentation.
- Explain the tradeoff between early mounting and waiting for font readiness, without hiding fallback text.
- Update the documentation site to Oddmash UI 0.10.0 (#158), use shared controls and semantic tokens (#129, #145), and localize header and footer branding (#139).
- Stabilize landing motion and first paint (#112, #120), compact mobile composition (#132), and verify every mobile specimen scene (#140).
- Expand UTF-16 source-range tests across all four locales (#130) and streamline CI without dropping required verification (#107, #117).
- Add browser regression coverage for stable breaks, delayed mount, font loading, and responsive changes.
