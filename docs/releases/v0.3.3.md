# Kowrap v0.3.3

- Improve balanced wrapping for Korean numeral and counter phrases such as `두 개로`, `세 가지를`, and `3 개로`.
- Preserve the minimum-line-count constraint, original text, existing greedy behavior, and the public API. A counting expression may still split when the available width requires it.
- Add deterministic regression cases based on the Boundra Korean documentation, including inflected counters and narrow widths.
