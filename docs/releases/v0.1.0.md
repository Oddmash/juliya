# kowrap v0.1.0

kowrap의 첫 공개 버전입니다. 프레임워크에 의존하지 않는 한국어 줄바꿈 엔진과 React/Next.js 어댑터를 제공합니다.

## 주요 기능

- 한국어 어절과 Unicode grapheme 보존
- 일반적인 순차 줄바꿈과 균형 최적화 전략
- 문장부호 및 한국어 수식 관계를 고려한 줄 경계 선택
- 긴 어절의 안전한 분리 및 원문 UTF-16 범위 유지
- Canvas 기반 폭 측정과 React `WrapText`
- SSR 및 Next.js App Router용 `SentenceText`

## 패키지

- npm: `@oddmash/kowrap@0.1.0`
- 공개 진입점: `.`, `/browser`, `/react`, `/react/server`
- Node.js 20 이상, React 18·19를 지원하는 선택적 React peer dependency

최초 릴리스의 기록이며 이미 발행된 npm 버전을 다시 배포하지 않습니다.
