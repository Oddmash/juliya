# Juliya 0.4.4

## Fixes

- Preserve Korean adverbial modifiers with likely predicates, including short modifiers, where the existing line budget permits. See #185 and #186.
- Exclude dative particles and ambiguous object/topic noun suffixes from the heuristic.
- Verify source restoration, width, emergency and explicit breaks, and default/explicit locale behavior.

## Compatibility

The existing public API, supported locales, framework integrations, and line count policy require no migration. The Korean preference remains a heuristic, not a grammatical guarantee.
