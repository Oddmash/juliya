# kowrap v0.1.1

최초 공개 버전의 릴리스 과정을 안정화하는 유지보수 릴리스입니다. 이 버전은 `v0.1.0`의 엔진과 공개 API를 그대로 유지합니다.

## 변경 사항

- GitHub Release 발행과 npm Trusted Publishing 연결
- Git 태그와 `package.json` 버전 일치 검사
- npm에 이미 존재하는 버전의 중복 발행 방지
- 검증을 통과한 패키지 아카이브만 OIDC로 배포하는 절차

## 호환성

런타임 동작과 공개 API의 변경은 없습니다. 기존 0.1.0 사용자는 별도 마이그레이션이 필요하지 않습니다.
