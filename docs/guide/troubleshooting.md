# 문제 해결과 제한 사항

## 줄바꿈이 적용되지 않아요

요소가 실제로 계산 가능한 폭을 가지는지 확인하세요. `display: inline`인 요소는 유효한 `clientWidth`를 제공하지 않을 수 있습니다. `JuliyaText`는 기본 block이지만 사용자 CSS로 바꿨다면 폭을 지정하는 것이 좋습니다.

```tsx
<JuliyaText as="p" style={{ display: 'block', maxWidth: 320 }}>
  긴 한국어 문장입니다.
</JuliyaText>
```

요소가 `display: none`이거나 아직 화면에 붙지 않았다면 초기 개행만 적용될 수 있습니다. 화면에 표시된 뒤 크기를 다시 관찰하거나 DOM 컨트롤러의 `refresh()`를 호출합니다.

### 줄이 예상보다 많아요

개발자 도구에서 텍스트가 들어가는 요소의 콘텐츠 폭을 확인하세요. 테두리와 좌우 패딩을 포함한 카드 너비보다 실제 글의 폭이 작을 수 있습니다. 기본 CSS와 비교할 때는 글꼴, 글자 크기, 글자 간격, 콘텐츠 폭을 동일하게 맞추세요.

아주 좁은 화면에서 긴 URL이나 API 이름이 한 줄에 들어오지 않으면 어절 안에서도 나뉠 수 있습니다. 같은 문장과 화면 폭에서 계속 재현되면 브라우저, 사용한 글꼴, 실제 줄이 나뉜 위치를 함께 기록하면 원인을 좁힐 수 있습니다.

## 긴 단어가 넘쳐요

`breakLongWords`를 false로 설정하면 폭보다 긴 어절이 그대로 남을 수 있습니다. 기본값인 true를 사용하면 grapheme 단위로 안전하게 나눕니다. 하나의 grapheme이 가용 폭보다 크다면 넘칠 수 있습니다.

## 다른 언어의 규칙으로 줄이 나뉘어요

React에서는 개별 `locale`이 Provider 설정보다 우선합니다. 둘 다 생략하면 한국어 규칙이 적용됩니다. i18n의 지역별 언어 태그를 사용하는 경우 [`JuliyaProvider` 연동 예제](react.md#i18n-연동)처럼 지원 언어로 매핑하세요. 서버 전용 문장 컴포넌트는 `locale`을 직접 전달해야 합니다.

## 강제 개행에서 RangeError가 발생해요

강제 위치는 0보다 크고 문자열 길이보다 작아야 하며, grapheme의 경계를 가리켜야 합니다. 이모지 결합 문자열의 중간 위치나 텍스트 수정 전의 인덱스를 전달하지 않았는지 확인해 주세요.

## Canvas 결과와 실제 화면이 조금 달라요

폰트 로딩, 탭, 복잡한 폰트 기능, 브라우저의 문자 간격 지원 범위에 따라 실제 DOM과 Canvas 폭이 다를 수 있습니다. Kowrap은 `ResizeObserver`가 제공하는 콘텐츠 폭을 우선 사용합니다. 첫 측정에서는 패딩과 테두리를 뺀 계산된 CSS 폭을 확인하고, 확인 가능한 값이 정수 폭뿐이면 작은 여유를 둡니다. 문서나 인라인 요소에 언어에 맞는 `lang`을 지정하면 브라우저가 알맞은 대체 글꼴을 선택하는 데 도움이 됩니다.

## SSR에서 처음 줄 위치가 달라져요

서버는 화면 폭을 알 수 없습니다. 최초 SSR은 원문과 강제 개행을 렌더링하고, 하이드레이션 후 실제 폭에 맞춰 재계산합니다. 서버에서 측정 없는 문장 묶음이 필요하면 `JuliyaSentenceText`를 사용하세요.

## Vue 또는 Svelte에서 텍스트가 중복돼요

디렉티브와 액션은 대상 요소의 자식 DOM을 소유합니다. 프레임워크의 동적 텍스트 렌더링을 같은 요소에 추가하지 마세요. 텍스트는 옵션의 `text`로 전달합니다. 직접 렌더링하려면 `observeKowrap`을 사용하세요.

## 디자인 시스템에서 사용하기

kowrap을 외부 의존성으로 사용하고 디자인 시스템의 번들 내부에 엔진을 직접 복사하지 않는 것이 좋습니다. 호환 가능한 버전 범위를 선언하면 로직 변경을 DS 재배포 없이 독립적으로 적용할 수 있습니다. 소비 프로젝트의 lockfile 갱신은 필요합니다.

## 지원 범위

- 한국어, 영어, 일본어 및 중국어 간체의 일반 텍스트와 제목, 짧은 문단이 주 대상입니다.
- 인라인 JSX와 HTML의 텍스트 태그를 지원합니다. 블록 요소, 이미지, 의사 요소, 자체 렌더링하는 React 컴포넌트는 측정 대상이 아닙니다.
- 한국어 수식 관계 판정은 휴리스틱이며 형태소 분석기 수준의 의미 이해를 제공하지 않습니다.
- 런타임에 별도의 사전 하이드레이션 스크립트를 주입하지 않습니다.
